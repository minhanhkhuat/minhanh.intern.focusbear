## Reflection 
1. What are the advantages of using Jupyter Notebooks for data analysis?
- Interactive Code Execution: Allows running code in discrete cells individually without re-executing the entire script, making data cleaning and iteration significantly faster.
- Inline Data Visualization: Displays plots, charts, and data frames directly beneath the execution code for immediate visual feedback.
- Integrated Documentation: Blends executable Python code with formatted Markdown explanations, supporting clear storytelling alongside data exploration.

2. How does Jupyter improve workflows compared to writing standalone Python scripts?
- Eliminates Re-loading Heavy Datasets: Large files or database queries remain held in memory across cells, avoiding slow reload times during exploratory data analysis.
- Rapid Prototyping & Debugging: Bugs can be isolated and fixed in single cells without disrupting the entire script execution flow.
- Self-Contained Reporting: Serves as both an active workspace and an exportable analytical report for non-technical stakeholders.

3. What are Markdown cells, and why are they useful in notebooks?
Markdown cells allow developers to format text using titles, lists, tables, and mathematical formulas alongside their code. They are essential because they:
- Document hypotheses, data transformations, and analytical decisions directly adjacent to the underlying logic.
- Organize long notebooks into scannable, logical sections.
- Help team members understand the context and business impact behind complex analytical pipelines.

4. How could Jupyter Notebooks be used for analyzing Focus Bear’s user trends?
- Cohort Analysis: Tracking focus session durations and habit completion rates across different operating systems (macOS, Windows, iOS, Android).
- Churn & Retention Modeling: Analyzing daily active user (DAU) retention patterns to identify drop-off points in user habit consistency.
- Feature Engagement Tracking: Running visual correlations between micro-break adherence and total uninterrupted daily focus time to evaluate feature efficacy.
