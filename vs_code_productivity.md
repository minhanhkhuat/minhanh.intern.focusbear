## Top 10 VS Code Shortcuts (macOS)

### Navigation

1. Cmd + P: Action Quick Open, Go to File.

2. Ctrl + G: Go to Line.

3. Ctrl + - : Go Back.

### Editing (Featuring Multiple Cursors)

4. Option + Click: Insert Multiple Cursors arbitrarily.

5. Cmd + Option + Down Arrow / Up Arrow: Insert Cursor Above / Below.
  
6. Cmd + D: Add Selection to Next Find Match.

7. Option + Up / Down Arrow: Move Line Up / Down.

### Debugging

8. F5: Start Debugging / Continue.

9. F9: Toggle Breakpoint.

### Terminal Commands

10. Ctrl + \:  Toggle Integrated Terminal.

## Reflection

1. Which shortcuts do you think will be the most useful in your daily work?
The Multiple Cursor variants (`Cmd + D` and `Cmd + Option + Down/Up`) along with Quick Open (`Cmd + P`) will undoubtedly be the most powerful tools in my daily development routine. As a developer, I frequently need to rename variables across a block of code or refactor repetitive data structures. Being able to spawn multiple cursors saves an immense amount of tedious, repetitive typing. Additionally, `Cmd + P` completely eliminates the need to use the trackpad to hunt down files in massive project structures.

2. How can keyboard shortcuts improve your productivity?
Keyboard shortcuts dramatically improve productivity by reducing the "friction" between thought and execution:

- Maintaining Flow State: Every time a developer lifts their hand to grab the mouse or trackpad, click a file, or highlight a word, it breaks their physical and mental momentum. Shortcuts keep your hands strictly on the keyboard, maintaining mechanical flow.
- Saving Cognitive Load: Instead of manually searching through deep folder hierarchies or scrolling line-by-line to find an error, shortcuts let you jump directly to your destination. This leaves more brainpower available for actual logic and problem-solving rather than navigating the editor's user interface.
