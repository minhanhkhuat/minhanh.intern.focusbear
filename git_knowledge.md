1. Yes, I have used Git before. I previously utilized it in academic settings, specifically for managing code and collaborating on university team projects.

2. I decided to use the integrated Git tool in VS Code as my primary Git client. It allows me to stage, commit, and push code directly within my development environment, keeping my workflow streamlined and efficient without needing to switch to a separate software application.

3. The most interesting thing I learned today is how Git acts like a powerful time machine for code. Understanding that commits are snapshot-based rather than just tracking file changes completely changed my mental model of how version control works. Seeing how easily Git can create isolated branches to experiment with new features without breaking the working production code is incredibly fascinating.
