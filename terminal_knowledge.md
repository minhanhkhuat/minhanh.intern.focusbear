# Terminal Knowledge & Reflections

## Terminal Client Choice

I chose to use iTerm2 combined with the default Zsh shell on my Mac.
Because iTerm2 is highly recommended within the macOS developer community because it offers vastly superior features compared to the built-in Terminal, such as split panes, search tools, and better color profile customization.

## Customizations Made

- Theme/Visuals: I customized the color profile in the Profiles settings to a dark theme that matches my VS Code environment, making it easier on the eyes during long sessions.
- Future adjustments: I plan to install "Oh My Zsh" and plugins like syntax highlighting later on as my workflow becomes more advanced.

## Most Useful Command Learned

The most useful command I learned today is `ls -la`. While the basic `ls` command lists visible files, adding the `-la` flags allows me to see all hidden configuration files (like `.git`) along with detailed file permissions and modify dates in a clean list format.
